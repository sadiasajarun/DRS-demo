MIS

Equipment Enlistment & Approved Catalogue

Manufacturers and distributors apply through the portal; the Technical Standards Committee evaluates against the Program technical standard. Every application is kept permanently.
Requirement coverage§3.3.1 · §3.2.1 · §3.9
  • Panel, battery and inverter manufacturers / authorised distributors apply through the portal for enlistment of specific models
  • Each application evaluated by the TSC against the approved technical standard; on approval the model joins the Approved Equipment Catalogue
  • Portal retains every application (approved, rejected, withdrawn), its technical documentation and the TSC decision as a permanent record
  • Catalogue records category, brand, model, key spec, datasheet / certification reference, TSC approval reference and date, status active / suspended / delisted
  • For inverter brands: read and write / remote-control API capability and commercial terms documented before the brand is finalised (§3.2.1)
