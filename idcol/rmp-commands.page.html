What the requirement asks of this screen

§3.2.1 · §3.9 · §3.1 · click to expand
  • RMP is the technical integration layer that communicates with every inverter or its gateway to obtain data and to execute the halt / resume called for by the CRM
  • For every brand proposed for enlistment, confirm whether the manufacturer API supports read / monitoring and write / remote-control access, and on what commercial or partner terms — documented and shared with IDCOL before the brand is enlisted
  • Every command and every acknowledgement or failure logged with timestamp, system ID, command type and result
  • Modbus / SunSpec fallback where cloud control is unavailable; no single-manufacturer lock-in
